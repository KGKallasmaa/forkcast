# forkcast

A meal planner app — currently in progress.

## Structure

| Folder | Stack |
| --- | --- |
| `frontend/` | React 19 + TypeScript + Vite, Zustand, Zod |
| `backend/` | Express 5 + TypeScript |

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

## Status

Early development. The backend entry point and full run instructions are still being documented here, and features, screenshots, and a live demo will be added as they land — this README does not claim features that aren't built yet.
